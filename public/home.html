About The Engine

XUI Ultimate is built on the XUI-FLASH-2.0.1-ALPHA core, written entirely in TypeScript and powered by the ultra-fast Bun runtime. It features intelligent caching using `UniversalCache`, multi-threaded downloading with chunk merging via FFmpeg, and a robust `ProtectionManager` to prevent abuse.

How To Use

  • 01. Select an Endpoint from the grid above.
  • 02. Enter the Target URL (e.g., YouTube, Instagram link) or Search Query.
  • 03. Select Quality/Format parameters if available.
  • 04. Click "Execute" to receive the JSON response containing download tunnels.
