Documentation

How do I use this API?
Send a simple GET request to any endpoint listed above. Include the query parameters (like ?url=) as specified. The API responds with a JSON object containing the direct download link and metadata.
What is the difference between Insta V1 & V2?
V1 (/insta) is optimized for speed and handles public posts efficiently.
V2 (/instav2) utilizes a more complex authentication method to retrieve restricted, age-gated, or private content that V1 might miss.
Are there rate limits?
Yes. To protect our infrastructure, we limit requests to 60 per minute per IP address. Excessive requests will return a 429 status code.
