Integration Guide
Send a GET request to the endpoint URL with the required query parameters (usually ?url= or ?q=). The API returns a JSON response containing metadata and a direct download_link. No headers required.
Instagram V1 vs V2
V1 (/insta): High-speed scraper for public posts. Fast response time.
V2 (/instav2): Uses session cookies to fetch age-gated or potentially restricted content. Use this if V1 fails.
Rate Limiting
To ensure stability, we enforce a strict rate limit of 60 requests per minute per IP. Exceeding this will result in a 429 HTTP status code.
