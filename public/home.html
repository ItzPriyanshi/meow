Documentation

How do I integrate this into my bot?

Simply make a standard HTTP GET request to the endpoints listed above. All endpoints return a JSON object containing the direct download URL (`download_link`) and metadata (`title`, `author`, `filename`).

Is there a rate limit?

Yes, to prevent abuse, we limit requests to 60 per minute per IP address. If you hit the limit, you will receive a 429 status code.

What is the difference between Insta V1 and V2?

V1 uses standard scraping which is faster but may fail on restricted posts. V2 uses a more robust (but slightly slower) authenticated session method to fetch private or age-gated content.
